# 10 · Technical viva questions and answers

The spoken answers use conversational Tamil-English. **Project evidence** describes this checkout. **General concept** describes reusable engineering theory. Where a design rationale is inferred, it is marked as an inference instead of attributing historical intent.

| Viva question | Spoken answer · Tamil-English | Project evidence, alternatives and edge cases |
|---|---|---|
| 1. What does AdvocaNote do? | “AdvocaNote lawyers-க்கு diary, case, hearing, task, calendar எல்லாத்தையும் manage பண்ண ஒரு workspace. React screen காட்டும்; FastAPI rules check பண்ணும்; MySQL records save பண்ணும்.” | Project: frontend routes and backend mounts. General: clean separation lets one API serve several UI screens. |
| 2. Where does React start? | “Vite page-ல root element இருக்கும். `main.jsx` createRoot பண்ணி App-ஐ mount பண்ணும். App route-க்கு சரியான page select பண்ணும்.” | `main.jsx`, `App.jsx`. Edge: direct navigation needs host routing fallback in a production SPA. |
| 3. What are state and props? | “Form values component state. Parent data-வை child-க்கு props-ஆ அனுப்பும். Update நடந்தால் React rerender பண்ணும்.” | `Register.jsx`, `LawyerLayout.jsx` passing user to onboarding. General: mutation/derived state can drift if duplicated. |
| 4. Compare React hooks. | “`useState` value state; `useEffect` API அல்லது listener மாதிரி outside work; `useRef` render வேண்டாத mutable reference; `useMemo` computed value; `useCallback` function identity stable பண்ணும்.” | `App.jsx` storage effect, `Subscription.jsx` selected plan, `AddDiaryEntry.jsx` media refs. Missing deps or cleanup can cause stale state or extra requests. |
| 5. Is a protected frontend route secure authentication? | “அது UX check மட்டும். Request server-க்கு போனதும் JWT, session, user role, ownership எல்லாம் backend check பண்ணணும்.” | `ProtectedRoute.jsx`, `AdminRoute.jsx`, `security.py`. Direct API calls bypass screen gates. |
| 6. Why Pydantic and FastAPI dependencies? | “Pydantic body shape, type validate பண்ணும். Depends மூலம் DB session, authenticated user inject ஆகும். Wrong input வந்தா handler run ஆகாம reject ஆகலாம்.” | `schemas`, `get_db`, router guards. Validation of type does not imply authorization. |
| 7. What is a JWT in this project? | “Signed access token-ல user subject, session ID, expiry இருக்கும். Backend signature verify பண்ணி session DB row-யும் check பண்ணும்.” | `security.py`. General: JWT signing provides integrity, not secrecy. Revoked sessions fail even if token time remains. |
| 8. Why hash passwords and refresh credentials differently? | “Password verify பண்ண slow password hash use. Random refresh token DB-ல digest-ஆ store பண்ணுறோம். DB leak ஆனா raw token நேரடியாக கிடைக்காது.” | `security.py`, `services/auth.py`. High-entropy random tokens differ from human passwords. |
| 9. How are OTP and Google different? | “OTP reset flow code check பண்ணும்; Google login Google credential validate பண்ணும். இரண்டும் user identity பற்றி, ஆனா purpose வேறு.” | `otp_recovery.py` HMAC and compare, `services/google.py`. Edge: expiry, incorrect audience, unavailable mail. |
| 10. What does SQLAlchemy session do? | “Session changes track பண்ணும். Flush SQL send பண்ணி ID கிடைக்கலாம்; commit permanent. Error என்றால் rollback.” | `database.py`, `diary.py`. General: one transaction can include several related rows. |
| 11. Trace Save Diary Entry. | “React form payload POST அனுப்பும். FastAPI permission, ownership, quota check பண்ணும். Case/court link, diary, needed child rows எழுதிப் commit பண்ணும்.” | `AddDiaryEntry.jsx`, `diary.create_entry`, `consume_daily_action`. Audio is a later request. |
| 12. Why lock quota? | “ஒரே நேரத்தில் இரண்டு request last slot-ஐ எடுத்துக்காம user/usage lock. Colombo date-க்கு ஒரு counter.” | `subscription_usage.py`, unique user/date. General: read-modify-write races disappear when serialized correctly. |
| 13. Calendar and notification difference? | “Calendar date view. Hearing/task/custom event data-வை combine பண்ணும். Notification reminder row read/unread state maintain பண்ணும்.” | `calendar.py`, `notifications.py`, `reminders`. Some reads reconcile custom reminders. |
| 14. What does Ollama do? | “Ollama local model server. Python service numbered statements, system prompt அனுப்பி Qwen JSON response கேட்டுக்கிறது.” | `legal_ai.ask_qwen`. Cloud versus local is a general alternative; source establishes local deployment, not the team’s full reasoning. |
| 15. Can AI outputs be trusted? | “JSON valid இருந்தாலும் fact correct என்று அர்த்தம் இல்லை. Evidence references, language, dates, task validation பண்ணி lawyer review கேட்கிறது.” | `safe_ai_point`, `extract_source_tasks`, reviewed suggestion API. Hallucination remains possible. |
| 16. What if Ollama is down? | “Some batches incomplete ஆக flag வரும்; rule-based fallback applicable இருந்தா notes கிடைக்கும். Manual diary save AI இல்லாமலும் செய்யலாம்.” | `legal_ai.py`, optional schema fields and wrapper errors. Do not promise a usable fallback for every input or outage. |
| 17. How is speech converted? | “Audio multipart upload. Backend temp file use பண்ணி Tamil அல்லது English Faster-Whisper model transcription எடுக்கிறது. Reviewed transcript தனியாக save ஆகும்.” | `voice_ai.py` and `voice_storage.py`. Codec, file size, model availability and accuracy are distinct issues. |
| 18. Why keep media on disk and metadata in MySQL? | “Audio body private folder-ல. MySQL entry ID, file key, transcripts store பண்ணும். Owner API வழியாக access.” | Inference: separation keeps binary storage distinct from relational metadata. Edge: failure between file write and DB commit. |
| 19. Where does the trial begin? | “Register முடிந்தாலே Stripe plan create ஆகாது. Lawyer dashboard access call eligible user-க்கு 30-day local trial create பண்ணும்.” | `subscription_access`, `subscription_trial.py`. First response can see stale transaction state. |
| 20. How do plans differ? | “Monthly admin limit use பண்ணும். Premium Monthly, Annual DB limit NULL என்றால் diary uncapped. Shared feature permission separately check ஆகும்.” | `subscription_usage.py`, `subscription_guard.py`. Current catalog prices are in chapter 06. |
| 21. Why hosted Checkout? | “Card form Stripe side. AdvocaNote session create பண்ணி URL return பண்ணும். Success redirect வந்ததும் backend original paid invoice verify பண்ணும்.” | `lawyer_subscriptions.py`, `stripe_webhooks.py`. A trapped or spoofed URL should not grant access. |
| 22. What is an idempotency key? | “Retry நடந்தாலும் same operation duplicate ஆகாம அடையாளம். இங்க local pending attempt save பண்ணி consistent Stripe key use பண்ணுறோம்.” | Checkout lock and reservation; network response loss edge case. |
| 23. How does an upgrade differ from downgrade? | “Upgrade full price hosted Checkout, paid verification பிறகு new cycle. Downgrade current period preserve பண்ணி Stripe schedule next phase-ல apply ஆகும்.” | `open_upgrade_checkout`, `process_checkout_upgrade`, `schedule_plan_downgrade`. Old-subscription retirement can require retries. |
| 24. How do cancellation and failed renewals work? | “Cancel period-end என்றால் paid end வரை access. Failed renewal paid date extend பண்ணாது. Status sync ஆன பிறகு Manage Billing மூலம் recover பண்ணலாம்.” | `cancel_my_subscription`, `handle_invoice_payment_failed`, status updater. Delivery/synchronization can lag. |
| 25. How do webhooks get verified? | “Raw request plus Stripe-Signature provider SDK verify பண்ணும். Event valid ஆனாலும் access update முன்னால் ownership, invoice, duplicate checks இருக்கும்.” | `stripe_webhook` and handler functions. Delivery failure and a rejected signature are separate cases. |
| 26. Why keep old Stripe Prices? | “New buyer rate latest price. Existing subscription old price-க்கு continue ஆகும். Both Price IDs same local plan-ஆ resolve ஆகலாம்.” | `get_plan_by_stripe_price`, `LEGACY_STRIPE_PLAN_PRICES`. Catalog price can differ from contracted renewal rate. |
| 27. What is a migration? | “Database structure change history. Alembic revision and parent chain order கொடுக்கும். Model file save பண்ணாலே database change ஆகாது.” | `migrations/versions`. Some startup DDL is outside migrations, so audit actual deploy separately. |
| 28. How do admin notifications differ from lawyer reminders? | “Lawyer reminders MySQL. Admin notifications separate SQLite. Role guard request-க்கு server side apply ஆகும்.” | `notifications.py`, `admin_notifications_api.py`. Different backup and persistence boundaries. |
| 29. What is CORS? | “Browser origin rule. Frontend origin allow பண்ணி API calls enable பண்ணும். அது authentication இல்லை.” | `main.py` middleware. Separate passwords/tokens and server-side access checks apply. |
| 30. What was verified for this study? | “Actual source trace பண்ணினோம். Previous Stripe Test Mode evidence தனியா mention பண்ணியிருக்கோம். இந்த documentation task-ல் real payment, AI model, SMTP, migrations execute செய்யவில்லை.” | Be honest about runtime constraints. Infer no business behavior solely from a filename. |
